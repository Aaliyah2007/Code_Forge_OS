# Code_Forge_OS

## Overview

Code_Forge_OS is an AI-powered onboarding and resume analysis platform developed using Python and Streamlit. The system helps candidates improve their resumes and provides an interactive experience for resume evaluation and career readiness.

## Features

* Resume Analysis
* AI-Based Resume Evaluation
* Candidate Onboarding Portal
* Interactive User Interface
* Streamlit Web Application

## Technologies Used

* Python
* Streamlit
* Pandas
* Docker
* GitHub

## Project Structure

* `app.py` – Main application file
* `requirements.txt` – Project dependencies
* `config.toml` – Configuration settings
* `Dockerfile` – Container configuration

## Installation

1. Clone the repository
2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```
3. Run the application:

   ```
   streamlit run app.py
   ```
